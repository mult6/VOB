# FAQ - Часто Задаваемые Вопросы

## 🔑 Адреса и ключи

### В чем разница между MetaMask адресом и Multi-sig Address?

**MetaMask адрес** (например, `0xABC...123`):
- Это ваш личный кошелек
- Используется для **подписи транзакций**
- Оплачивает gas fees (BNB)
- Получается автоматически при подключении MetaMask
- **НЕ вводите его вручную в бот!**

**Multi-sig Address** (например, `0x742d35...`):
- Это адрес вашего **профиля на Opinion Trade**
- Используется для **хранения средств** (USDT)
- Хранит ваши торговые позиции
- Нужно **получить на app.opinion.trade → My Profile**
- **Этот адрес вводите в настройках бота!**

### Где взять Multi-sig Address?

1. Откройте [app.opinion.trade](https://app.opinion.trade)
2. Подключите MetaMask
3. Создайте профиль (если еще не создан)
4. Перейдите в **"My Profile"** или **"Settings"**
5. Найдите **"Multi-sig Wallet Address"**
6. Скопируйте этот адрес

### Можно ли использовать один и тот же адрес для MetaMask и Multi-sig?

Технически это разные адреса:
- **MetaMask** - для подписи
- **Multi-sig** - для хранения

Но они **могут совпадать**, если вы используете тот же адрес для профиля Opinion.

## 🔐 Безопасность

### Безопасно ли подключать MetaMask к боту?

✅ **Да, абсолютно безопасно!**

Причины:
- Приватный ключ **НЕ извлекается** из MetaMask
- Сервер **НЕ имеет доступа** к приватному ключу
- Все транзакции подписываются **локально в браузере**
- Сервер получает только **подписи**, а не ключи

### Что может сделать сервер с моим кошельком?

**Ничего!** Сервер:
- ❌ НЕ может украсть средства
- ❌ НЕ может совершить транзакцию без вашего подтверждения
- ✅ Может только **запросить подпись** (вы увидите pop-up в MetaMask)
- ✅ Может только **управлять ботом** (логика торговли)

### Нужно ли вводить приватный ключ где-то?

❌ **НЕТ! Никогда не вводите приватный ключ!**

При использовании **web-версии**:
- Приватный ключ остается в MetaMask
- Вы только **подтверждаете транзакции** в MetaMask

При использовании **локальной версии**:
- Приватный ключ хранится в `.env` файле на вашем компьютере
- Файл `.env` должен быть в `.gitignore` (не публиковать!)

## 📝 API ключ

### Как получить Opinion API ключ?

1. Заполните [форму заявки](https://docs.google.com/forms/d/1h7gp8UffZeXzYQ-lv4jcou9PoRNOqMAQhyW4IwZDnII)
2. Укажите:
   - Email
   - Цель использования (Trading bot / Market making)
   - Описание проекта
3. Дождитесь одобрения (обычно 1-3 дня)
4. Получите ключ по email: `opn_prod_xxx...`

### Можно ли использовать один API ключ для нескольких ботов?

✅ **Да, можно!**

Один Opinion API ключ работает для:
- Opinion OpenAPI
- Opinion WebSocket
- Opinion CLOB SDK

Вы можете запустить несколько ботов с одним ключом.

### Безопасно ли вводить API ключ на сервере?

✅ **Да, относительно безопасно.**

API ключ:
- Не дает доступа к средствам
- Только разрешает использовать Opinion API
- Хранится на сервере **зашифрованно**
- В худшем случае: кто-то использует ваш лимит API запросов

**НО:** Приватный ключ - **НИКОГДА** не передавайте!

## 💰 Средства и торговля

### Сколько нужно средств для запуска?

**Минимум:**
- $5 BNB для gas fees
- $50 USDT на балансе Opinion для торговли

**Рекомендуется:**
- $10-20 BNB для gas
- $100-500 USDT для торговли

### Где хранятся средства?

```
BNB (gas fees)
  ↓
  В вашем MetaMask кошельке
  (расходуется при подписи транзакций)

USDT (для торговли)
  ↓
  На вашем Multi-sig Address в Opinion
  (используется ботом для ордеров)
```

### Как пополнить баланс на Opinion?

1. Откройте [app.opinion.trade](https://app.opinion.trade)
2. Перейдите в **"Deposit"** или **"Wallet"**
3. Выберите USDT
4. Следуйте инструкциям для депозита
5. Средства появятся на вашем Multi-sig Address

## 🤖 Работа бота

### Как бот размещает ордера без приватного ключа?

**Процесс:**
1. Сервер **генерирует** unsigned ордер
2. Сервер **отправляет** запрос на подпись через WebSocket
3. **Браузер** показывает pop-up MetaMask
4. **Вы подтверждаете** в MetaMask
5. **MetaMask подписывает** локально
6. **Браузер отправляет** подпись обратно на сервер
7. Сервер **размещает** signed ордер в Opinion API

### Нужно ли держать браузер открытым?

❌ **Нет!** После запуска бота:
- Бот работает на **сервере** 24/7
- Браузер нужен только для **подтверждения транзакций**
- При новом ордере вы получите **уведомление** в браузере (если открыт)
- Можно закрыть браузер, бот продолжит работу

**НО:** Для подтверждения новых ордеров нужно:
- Открыть браузер
- Подключиться к боту
- Подтвердить транзакции

### Как часто нужно подтверждать транзакции?

Зависит от настроек бота:
- **Dual Side стратегия**: ~каждые 30 секунд (при изменении цен)
- **High Probability**: реже, только при выгодных ценах
- **Custom**: по вашим настройкам

Можно настроить **автоподтверждение** (в разработке).

### Как остановить бота?

**Через веб-интерфейс:**
1. Откройте dashboard
2. Нажмите **"Остановить бота"**
3. Все активные ордера будут отменены

**Через API:**
```bash
curl -X POST https://opinion-api.kirst-defi.xyz/api/bot/stop \
  -H "Content-Type: application/json" \
  -d '{"wallet_address": "0x..."}'
```

## 🆘 Решение проблем

### Ошибка: "Multi-sig Address invalid"

**Причина:** Неправильный формат адреса

**Решение:**
1. Проверьте что адрес начинается с `0x`
2. Убедитесь что скопировали **именно Multi-sig Address** из Opinion профиля
3. Не используйте адрес из MetaMask напрямую

### Ошибка: "Insufficient balance"

**Причина:** Недостаточно средств

**Решение:**
1. Проверьте баланс USDT на Opinion (минимум $50)
2. Проверьте баланс BNB в MetaMask (для gas)
3. Пополните через app.opinion.trade

### Ошибка: "WebSocket disconnected"

**Причина:** Потеряно соединение с сервером

**Решение:**
1. Проверьте интернет-соединение
2. Перезагрузите страницу
3. Переподключите MetaMask
4. Проверьте статус сервера

### Бот не размещает ордера

**Причины:**
1. Неправильный Multi-sig Address
2. Недостаточно USDT на балансе
3. API ключ неактивен или неправильный
4. Сеть не BNB Chain

**Решение:**
1. Проверьте все данные в настройках
2. Посмотрите логи в dashboard
3. Проверьте статус на app.opinion.trade
